# Anatomy study tool

A single-page study tool for my anatomy class. Open `index.html` in any browser.

- **Practice questions** – bellringer practice plus MCQ sets for lectures 4–9 (Lecture 9: osteokinematics & arthrokinematics, 183 questions).
- **Label diagrams**, **Plexus guide**, **Root game**.
- **Anatomy ID** – click / name / type the structure on real anatomy plates: hand & skeleton bones, skull, foot, pelvis, thorax, brachial/lumbar/sacral plexus, upper & lower limb muscles, limb nerves, and nerve → muscle matching. Timed rush mode, streaks and sound.
